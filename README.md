# Сайт «ЛиллиПап»

Статическая версия сайта для GitHub Pages. Сборка и сервер не нужны. Все файлы сайта и фотографии находятся в этой папке, а ссылки на них относительные — сайт будет работать и в корне репозитория, и в репозитории проекта.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень GitHub-репозитория: `index.html`, `styles.css`, `script.js` и пять файлов `.jpg`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
4. Дождитесь завершения публикации. GitHub покажет адрес сайта в том же разделе **Pages**.

Имена файлов и регистр букв в них нужно сохранить: пути к CSS, JavaScript и фотографиям указаны относительно `index.html`.

Фотографии сейчас вырезаны из присланного макета. Для публикации можно заменить их исходными фотографиями студии, сохранив имена файлов.
